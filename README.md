## 📘 Session Overview

In today’s session, we covered the fundamentals required for backend development, focusing on **Unix commands**, **Version Control Systems**, and **Git & GitHub**. The session helped learners understand how developers manage code efficiently and collaborate in real-world projects.

---

## 🖥️ Topics Covered

### 1. Unix Commands

Learners were introduced to basic and commonly used Unix commands, including:

* `ls` – list files and directories
* `cd` – change directory
* `pwd` – show current directory path
* `mkdir` – create a new directory
* `rm` – remove files or directories
* `cp` – copy files
* `mv` – move or rename files

These commands help developers navigate and manage the system efficiently.

---

### 2. Version Control System (VCS)

* Introduction to Version Control Systems
* Importance of VCS in software development
* How VCS helps in tracking changes, collaboration, and maintaining code history

---

### 3. Git and GitHub

Learners explored Git as a distributed version control system and GitHub as a code hosting platform.

#### Git Commands Covered:

* `git init`
* `git status`
* `git add`
* `git commit`
* `git log`
* `git clone`
* `git push`
* `git pull`

---

### 4. Git Branches

* What is a branch in Git
* Why branches are used
* Creating and switching branches
* Working on features using branches

---

### 5. Git Commits

* Understanding commits
* Writing meaningful commit messages
* Importance of commits in tracking project progress

---

## 🎯 Learning Outcome

By the end of the session, learners were able to:

* Use basic Unix commands confidently
* Understand the role of version control systems
* Work with Git and GitHub
* Create branches and manage commits effectively
